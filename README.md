# muftdevelopmentfoundation.org.uk

Website for **Muft Development Foundation**, registered charity 1218194
(Charity Commission for England and Wales).

Vite + React + TypeScript, prerendered to static HTML at build time and served by
Vercel. News stories are markdown in `content/news/`, written through the editor
at `/admin`.

```
npm ci
npm run dev
npm run build
```

**Read [HANDOVER.md](HANDOVER.md)** — how trustees publish a story, which accounts
own what, how the domain and the charity's email fit together, and the rules about
the bank details shown on the Donate page.
